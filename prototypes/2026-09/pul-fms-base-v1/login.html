登录页

系统统一身份入口 · 权限体系的起点

一句话概括：所有用户从这里进入系统（客户新版登录流程 2026-09-21）：超级用户先选院区，非超级用户自动进入其唯一所属院区；既属于库房又属于药房的用户必须先选「库房管理 / 药房管理」，再选具体库房/药房——登录上下文是行数据自动隔离的第一道闸门。

使用角色 + 上下游
👥
超级用户 + 业务用户
超级用户不指定院区（只做权限/字典，不参与业务）；业务用户指定唯一院区 + 授权多个库房/药房
🔀
上下游
上游：浏览器直接访问 → 本页；下游：登录成功 → 工作台，顶栏显示当前上下文（院区-库房/药房）并可随时「部门切换」
如何使用
1
输入账号密码
或点击下方演示账号芯片一键填充（演示密码统一 123456）；禁用账号直接拒绝
2
院区分流
超级用户选院区；非超级用户自动进入其唯一所属院区（只读展示）
3
选业务模块（仅双栖用户）
既属于库房又属于药房 → 先点「库房管理 / 药房管理」大卡，再选具体库房/药房；单一授权用户直达工作台
示例
场景示例
用 keeper.wang（库管员，仅授权中心库）登录 → 无任何选择直接进工作台；用 yq.sun（授权分院库（东）+ 急诊药房（东））登录 → 院区锁定「东院区」→ 必须先选「库房管理 / 药房管理」→ 再选具体节点；用 admin（超级用户）登录 → 先选院区，再选模块与节点。
场景呼应
登录页 → 工作台 → 各业务页
登录态通过 sessionStorage 跨页共享；未登录直接访问业务页时自动注入演示账号并标记「演示模式」，方便评审时从任意页开始讲解。
