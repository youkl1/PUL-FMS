领用出库单

库房管理 · 出库单台账：筛选 + 新增 + 审核跳转 + 三页签明细

一句话概括：纯出库台账：只列过账领用单（已出库·待入库 / 已入库·待上架 / 已上架推导），与药房「领用入库单」一一对应；待提交 / 待出库 / 作废统一在「领用备货单」页，本页只读查明细。

使用角色 + 上下游
👤
库管员
筛选出库单 → 点选看码详情/药品清单（只读台账，无操作）
🔀
上下游
上游领用备货单扫码备货；下游药房入库/上架闭环
如何使用
1
筛选单据
按单据编号 / 领用药房 / 上架货位 / 状态 / 日期区间查询
2
点选看明细
码详情 / 药品清单 / 无库存码三页签，行内「码列表」弹窗
3
对应药房入库
「已出库·待入库」单出现在药房「领用入库单」待入库；药房逐码核对确认后本页状态变「已入库·待上架」，全码上架后推导「已上架」闭环
示例
中心库 → 门诊药房
「领用备货单」备货扫码审核出库 → 本页出现该单（已出库·待入库）→ 药房「领用入库单」逐码核对确认 → 本页状态变「已入库·待上架」，全码上架后推导「已上架」闭环。
场景呼应
单据来源：领用申请 / 库房制单 / 直接出库
「领用申请」由药房申请单流转而来，药品清单按计划行展示扫码/实物对比；「库房制单」由库房缺货驱动开待提交草稿，提交后照常备货；「直接出库」无明细行，药品清单按已扫码聚合。无库存码在备货扫码时已拦截，页签保留对齐老系统。
