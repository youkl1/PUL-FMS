处方药品汇总查询

出库管理 · 对账视角「发出去多少」：门诊 + 住院发药量按药品×批次汇总

一句话概括：把门诊处方与住院摆药已绑定的码按 药品×批次 汇总（数量=码 count 派生），门诊/住院拆两列，点行下钻到单据与逐码明细；已退药单的码已还回在架、不计入。

使用角色 + 上下游
👤
药房负责人 / 药事会
按时间段看发药结构与用药量，支撑补货与点评
🔀
上下游
上游：处方发药扫码 / 摆药单批量赋码；互补：处方药品明细查询（按人按单视角）
如何使用
1
筛范围
按药品名/通道（门诊/住院）/日期段
2
看汇总
药品×批次一行：门诊量 + 住院量 + 合计
3
下钻
点行看单据与逐码；住院单深链HIS摆药单查询
口径说明
发药量 = 进行中 + 已完成 单的已绑码
与库存占用口径完全一致（occupiedRxCodes 同一批状态），所以「汇总发出量 + 药房在架 + 退药还回」能勾稽到领用入库单总量；已退药单排除在外，避免重复计数。
场景呼应
汇总（本页）⇄ 明细（处方药品明细查询）= 同源两视图
本页回答「某药某批发了多少、发到哪」，明细页回答「某人拿了什么」；数字同源（都是已绑码 count），可互相勾稽。
