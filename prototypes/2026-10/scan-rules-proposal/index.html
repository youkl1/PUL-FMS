③ 扫码判定树与审核规则 · 明细

「是否按药品清单扫码」是扫码录入页面的版面开关：默认值按单据类型（有码单 / 清单单 = 是、人工单 = 否），操作员可切。

扫入一码（折合 = 本码折基本单位数）
码对应药品 不在清单
比对清单 = 是✕ 不能插入
比对清单 = 否✓ 能插入，扫码总数 += 折合
码对应药品 在清单
该行计划数量 ≤ 0✓ 能插入（不限制总数）
计划数量 > 0 且 ≥ 已扫总数 + 折合✓ 能插入
计划数量 > 0 且 < 已扫总数 + 折合✕ 不能插入（超量拦截）
要点（修订①）：开关与超量解耦 开关只控制「清单外药品能不能进」；超量校验与开关无关 —— 只要药品在清单内且有计划数量，超量恒拦截。
